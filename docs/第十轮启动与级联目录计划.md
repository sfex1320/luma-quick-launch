# 第十轮启动配置、缩略图与级联目录 Implementation Plan

> 使用 subagent-driven-development 按以下边界实现、测试、审查；用户本轮已明确授权功能，沿用现有分支与运行目录，不重复请求批准。

**Goal:** 手动覆盖项目命令，文件图标展示静态内容缩略图，持续长按可以逐级展开目录，鼠标悬停分成打开/进入大点击区。

**Architecture:** 保持协议1和状态schema1。LaunchItem增加可选 `launch:{command,workingDirectory}`，仅文件夹可用；旧数据省略该字段仍有效，保存不执行。沿用project.detectTest/runTest令牌方法，根目录手动配置优先，子目录自动识别；运行只读已保存配置。新增folder.getThumbnail，输入仍是宿主目录令牌，返回PNG/null。前端级联菜单共用根手势，最多保留12层，屏幕不足允许横向浏览已有层而不删除父菜单。

**Tech Stack:** React/TypeScript、现有WebView2/WPF/Windows Shell。

**Spec:** 本文用户语义与下列验收即本轮规范；协议文末随后同步最终实现。

## Global Constraints

- 挂机冻结副本仍运行，禁止变更或终止；不开第二原生GUI，不污染用户配置。只做源码、单元与无界面E2E验证/候选构建，真实原生验收随后进行。
- 原有650/600ms收放、visibilityId、普通窗口置顶、不提权、配置CAS原子保存不变。
- 只有用户手动保存的命令可作为自定义CMD命令运行，不接受run请求中的命令或路径。command单行非空最多1000字，workingDirectory非空绝对路径最多4096字；编辑与导入不执行。
- 多层目录保留父层；长按300ms展开，持按移动到文件夹驻留450ms进入下一层，不打开真实资源；松手只启动当前位置目标一次，移出取消，Escape/blur取消。点击进入区域只浏览不启动。快速点击在250ms悬停分割前打开默认项。
- 缩略图仅静态图标，不开弹窗、不视频播放、不递归扫盘。优先Windows Shell缩略图，缺少PSD/AI/CDR对应系统处理器则保留文件图标，不谎称通用解码。读取与缓存/队列均有界，慢处理不得阻塞window.sync。
