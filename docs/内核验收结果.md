## K3 · 真实启动

自动测试（fake shell 统计副作用次数，全部通过）：

- 不存在的项目/入口 → PATH_NOT_FOUND，不触碰 Shell；
- 中文空格路径（`D:\我的项目\素材 库\`）验证通过并启动；
- 命令串（cmd /c、powershell -command、start、&&）与 URL、相对路径、内嵌 NUL 全部拒绝（INVALID_REQUEST）；
- 失效路径（探针不可见）→ PATH_NOT_FOUND；
- 同一请求 id 60 秒内重复 → 只启动一次；不同 id 分别启动；
- 不可达网络路径探针超时 → PATH_NOT_FOUND 且不重试（探针次数断言为 1）；
- Shell 权限错误 → ACCESS_DENIED 中文反馈。

启动实现：`ProcessStartInfo { UseShellExecute=true }` 由系统 Shell 解释（.lnk/file/folder/app），不拼命令、不走 cmd/PowerShell；存在性探针在后台线程 5 秒超时。

**限制**：真实打开资源管理器/应用的端到端点击未在本验收中执行（测试机输入被数位板独占，见"环境限制"）；单击主目录/长按松手打开的交互请用户手动确认。

- **200 次展开收起**（激活信号驱动完整 UI 往返，140.9s）：内存 361.3 MB → 326.2 MB，**无持续增长**（GC 回收后反而下降 35.1 MB）。
- **GPU**：GPU Engine 系统全量利用率 0.25%（含所有其他应用；无按进程稳定 API，记为限制）。
- 对照原计划目标：CPU <1%（整机口径实测为 0%）、隐藏无每帧轮询（collapse 检查仅展开期 150ms×3，隐藏期 timer 全停）——达成；**私有内存 <150 MB 未达成**（实测 359 MB，7 进程为 WebView2/Chromium 运行时固有基础开销，含 GPU/网络/渲染服务进程）。如实记录，不以预设数字填报。

交付包：`APP/native/Luma/`（自包含 win-x64 157.7 MB，无需 .NET 运行时与 Node.js；含 `Luma.exe`、运行时、`dist/`；性能测量与真实运行均基于该交付包 exe）。构建脚本 `scripts/build-native.ps1`（前端 build → 停止运行实例 → 内核测试 → self-contained publish → 拷贝 dist → 产物校验）。

## 环境限制（如实记录）

1. **测试机输入被数位板/触摸栈独占**：`SetCursorPos`/`SendInput` 移动光标无效（光标被锁定在 (0,2159)，注入返回成功但位置不变）。因此"真实鼠标顶边驻留 180ms 唤出"与"长按滑选打开子目录"只能验证到消息管道与唤出/收起链路（托盘信号路径全链路实测通过），真实指针交互请用户手动验收。
2. 100%/125%/200% DPI、显示器热拔插、主屏回退：显示器设置属于用户工作环境，本验收未改动；多屏 150% 场景已实测。`MonitorService` 的 DisplaySettingsChanged → visible=false → 重定位 → visible=true 序列已实现。
3. 单实例激活、托盘菜单点击、开机启动选项：无输入注入条件，代码已实现未逐项人工点验。
4. 背景视频场景：浮岛 UI 本身无视频内容，性能测量以"展开静止"替代，GPU 按引擎计数器总量对比基线（无按进程稳定 API）。
