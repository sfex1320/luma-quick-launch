## 使用方式

1. 在项目/快捷项的编辑窗口，为文件夹启用“手动启动命令”，填写工作目录与CMD命令，保存后该根目录优先使用手动配置。点击“手动启动”才执行；可用“恢复自动识别”撤销覆盖。支持与绑定目录不同的工作目录。CMD无法将UNC共享直接作为cwd时明确提示使用映射驱动器。
2. 子目录的文件图标显示静态内容缩略图，不新增预览窗口或视频播放。通过Windows Shell读取图片、视频及设计文件的系统缩略图；PSD/AI/CDR是否可显示取决于已安装的Shell处理器，不支持时稳定回退。已实测PNG，尚未实测所有视频、PSD/CDR/AI格式。
3. 快速单击直接打开；按住300ms展开菜单，继续按住移动到文件夹上停留450ms，右侧展开下一层，父层与成组入口保留。松手打开当前目标，移出取消。屏幕不足时横向浏览，最多同时保留12层，格子88×94。
4. 文件夹悬停250ms出现两个等宽大区域：“打开”和“进入”。进入只浏览；快速点击不等分割仍直接打开。键盘ArrowRight也可进入。

展开导致布局变化时，必须继续移动鼠标才允许松手打开，避免列移位把另一个图标带到鼠标下误启动。收放保持650/600ms滑移，没有增加后台装饰动画。

## 实现边界与审查

- 状态schema1新增可选launch；protocol1沿用detectTest/runTest保存ID及短期令牌。保存/识别不执行。命令或cwd修改使旧任务失效；同工作目录终端打开/启动中返回BUSY。
- 原生缩略图固定2个STA工作线程；排队、待处理、缓存及字符数有上限，过期队列不迟到提取，COM/GDI释放。前端可见图标懒加载、2并发32排队、128缓存项，离屏移除图像，无全盘扫描或重试循环。
- 交叉审查修复了命令trim会改变用户字面值、工作目录控制字符漏检，以及合法文件名中的shell关键词被误认为命令的问题。级联列仅在可视面板内命中，不把屏幕外列加入原生区域；成组父菜单不卸载，持按捕获持续有效。
- 本地命令属于用户显式授权执行，非代码沙箱；自动识别的“不恢复依赖”限制保持。没有通过接口接收任意临时命令/路径。
