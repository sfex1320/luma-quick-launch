# 第十四轮：收藏、目录布局与会话记忆

## 实现

新增常态五角星：普通项目、组内软件/网址、真实目录文件与子目录、最近项目均可收藏。主栏分隔展示收藏，底色略深，复用已有玻璃图标、长按及打开行为。收藏保存快捷引用快照、手动取消，不移动或复制源文件；跨窗口继续使用既有乐观并发保存和广播。

根目录冗余标题行已删除，最深层刷新在关闭按钮左边。标准窗口4列、2整行，88×94固定格子，窄屏可滚动。末尾移动按钮现在有明确用途提示，准备了实际目录项后仍须确认移动。

收起或成功打开后保存上次项目与目录链，再次唤醒恢复。会话缓存有界（32项目×每项目32根×11子层），只存名称链，重开后逐级重新读取；失效路径截断，软件退出后清空。收藏独立持久保存。

## 稳定性修复与审查

原生旧热区计时未重新确认实际命中，且裸左键松开可触发唤醒。现在计时结束重验坐标、命中、布局、暂停和按键；单击要求热区内配对按下/松开。OLE与显式快捷键不受此鼠标驻留规则限制，650/600ms动画保留。

独立审查另发现并修复：成功打开后面板仍可保持交互并盖住目标窗口；收藏框间距未计入自动宽度；星标起点可能进入实际目录拖动链。收藏匹配使用随项目数据更新的索引，避免鼠标滑选时对全部收藏反复扫描。没有添加常驻轮询、全盘递归或后台预览播放。
