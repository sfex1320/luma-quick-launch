# 第三轮：回收过渡与拖放修复

日期：2026-09-19。交付位置：`APP/native/Luma/Luma.exe`。

## 修复结果

1. 原实现隐藏时同时卸载前端并 Hide 原生窗口，退出没有过渡。现在保留整个面板播放约 180ms 回收动画，再确认原生隐藏；中途重新进入从当前帧反向展开。
2. 额外修复点击收起后被旧 180ms 驻留定时器重开，以及动画移到静止鼠标下造成的 pointerenter 误展开。新增回归先失败、修复后连续三次通过。
3. 修复旧退出消息队列污染新唤出：新增可选 visibilityId 并原样回传，在区域、交互和可见性状态更新前拒绝旧编号。protocol 保持 1。
4. 每个屏幕的热区注册 Windows OLE 文件拖放目标；文件拖到隐藏热区即可唤出，再移动到面板松手。热区只负责唤出，不移动或执行文件。
5. 鼠标按压、拖放、等待导入、键盘操作、打开堆叠期间明确保持展开；原生使用实际物理区域判断，避免拖拽图层遮住鼠标命中后误收起。
6. 设置页空白拖入创建独立快捷项，已有卡片拖入加入堆叠；编辑弹窗支持批量拖入和去重，保存后生效；卡片手柄可拖动排序，箭头操作保留。

## “项目”与五个目录

项目只是一个逻辑分组。它可以绑定五个不同位置的目录，也可以混合软件快捷方式、文档；不要求它们在同一磁盘父文件夹下，也不会移动原文件。每个堆叠最多 200 个入口，单批最多拖入 100 个。单击打开第一个入口，长按约 300ms 后滑向其他入口松手打开。操作说明已加入设置页及编辑表单。

缩略图按用户“也可以不插”的选择保留为未实现项，本轮继续使用水晶图标，没有增加文件夹扫描或后台缩略图任务。
