# 第十四轮：收藏、会话记忆与唤醒防误触

用户已授权实现、自验、直接覆盖 APP、上传 GitHub 和保留桌面入口。本轮不另行交付候选。收藏保存期限已询问，未答复时采用可手动取消的持久快捷引用；目录浏览记忆明确仅当前进程会话。

## 数据与文件边界

- 收藏复用现有 Project/LaunchItem 启动模型，Project 增加可选 `favorite: boolean`，缺省 false；收藏集合与普通集合分别展示，收藏底色稍深、以分割线区隔。仍计入最多100个集合、每组200入口。收藏保存名称/路径引用快照，使用新的已保存 ID；取消收藏只移除此引用。
- 子目录收藏必须通过现有 folder.getPath 的当前令牌解析；收藏不会直接执行、移动或复制磁盘文件。最近记录使用宿主已返回的具体路径。软件、网址继续沿用原 Shell/URL 安全校验与复用。
- 普通成组/收藏的拖拽仍只改链接；末尾移动按钮只处理真实目录项，经明确表单确认后执行，空待移动状态点击必须解释用途。
- app.saveState 的 expectedRevision、原子存储和跨窗口状态同步不改变。protocol/schemaVersion 仍为1，新增字段兼容旧配置。

## 交互

- 常态图标右上角独立五角星；星标操作不冒泡到打开/长按/拖动，收藏区再次点击取消。子目录、组内工具和最近项目均可收藏。
- 根目录冗余路径行移除；刷新在标题栏关闭按钮左边，作用于当前最深层目录。目录标准4列×2行，固定88×94格子，屏幕不足时缩减可见范围并可滚动。
- 收起再展开、打开文件导致收起后保留上次面板和目录链；明确关闭菜单清除当前显示。切换项目保存各自最近链，最多32个项目，每项目32个根目录/每根11子层。保存目录名称链并重新解析宿主令牌，不重用过期令牌；失效路径截断。退出进程清空，不写用户配置。
- 原生热区到期再次检验当前位置、实际命中、按键与屏幕布局；外部按下后滑入释放不得触发单击唤醒。显式快捷键、OLE拖入与650/600ms动画保持。
