# 第二十三轮修正与交付记录

## 已定位问题

1. 入口计数字号原选择器依赖 `:last-child`。加入筛选框后它不再匹配，计数继承较大字号，并可被 flex 挤成逐字竖排。改为独立类、固定 11px/18px、不收缩；标题与路径单行省略，保留完整提示。目录磁贴此前明确使用两行 line-clamp，现统一单行。
2. 软件入口此前统一提供最近项目导航，即使宿主无法读取专属历史。新增只读能力查询，沿用保存入口的实际软件解析，只对有可靠来源的软件展示最近；其余软件只有 AppWindow 图标的“打开软件”。所有悬停、长按、方向键和菜单使用相同判断。
3. 热区重排原先会直接根据静止位置恢复驻留计时，无需新鼠标输入。移除这条路径，布局、显隐和离开重置位移基线；只有有效鼠标来源及坐标变化才开始新的驻留。已有 180ms 停稳/3px 容差及点击、OLE、显式唤出保持。

## 文件拖放

普通模式默认/Ctrl 复制、Shift 移动、Alt 创建 `.lnk`（Alt 优先）；主栏文件夹、组内文件夹、目录磁贴和目录列空白均有明确落点。组含多个目录或主栏空白时列出目标选择。编辑模式只整理快捷引用。

源来自 WebView 真实文件对象或已保存 ID/目录令牌；目标只接受宿主目录令牌。确认动作和目标后提交。同名不覆盖，源与目标重解析路径及自包含拒绝；移动目前仅同卷，禁止跨卷复制后删除。复制保留 NTFS 命名流，包括 Zone.Identifier；EFS 暂不支持。每批顶层最多 100 项、复制树 200 项/16 层/2 GiB，命名流每项 32 个、每批 128 个；超限明确返回，不静默截断。

操作占用有界后台工作线程；提交后的最终响应一直保留，超过普通八秒桥接期限不假报失败。部分提交返回已改动数量并刷新目录，不能声称全部成功。Alt 创建快捷方式不启动文件，也不配置键盘快捷键。
