# 第十八轮交付报告：软件内更新、分层动画与编辑增强

2026-09-23 · 版本 **0.4.0** · 交付源码 `bcc3dbfe08e94930e9e90568893fcd00ef5f13cf`

## 需求与实现

### 1. 菜单收缩/展开逻辑（动画）

- **分层收缩**：面板收起时，打开中的堆叠/更多面板先快速淡出（`stack-leaving`，三档占 200/160/120ms），主栏随后完整位移收起；展开顺序保持先主栏后子菜单。涉及 Escape、自动隐藏、启动后收起、手柄点击、原生唤出隐藏五条路径，统一走 `leaveStack`。
- **整体加快 + 可调速度**：`preferences.motionSpeed`（relaxed/standard/brisk，外观页三档选择），主栏推出/收起时长 650·600 / 520·450 / 380·320ms。standard 为新默认，比旧 600ms 更快；relaxed 保留原节奏。原生 DTO 增加 motionSpeed 可空透传（否则 StateStore 往返丢字段）。
- 协议未改：无新方法名/字段变更之外的语义；`docs/内核接口协议.md` 文末有本轮补充。

### 2. 菜单编辑逻辑

- 点击"整理图标"不再关闭已打开的二级及后续菜单（面板保持展开，可直接继续编辑）。
- 组列磁贴编辑能力原样保留（左上 X 移除快捷引用、左下↗移到主面板、拖拽合并/排序）；目录列的真实文件项维持既有目录四动作（新建/重命名/移动均经确认），编辑模式下面板不关闭即可连续操作。
- 编辑界面角标布局（用户指定）：左上=叉叉、右上=收藏（收藏星现在在编辑/非编辑两种模式都显示）、右下=快捷键徽标。

### 3. 界面布局

- 收藏按钮进入编辑界面：磁贴左上 X、右上 ☆，与既有非编辑模式星标共存。
- 图标虚线框加大：编辑模式虚线框 `outline-offset` 由 -3px 改为 1px（框体落在图标外侧、更大），图标尺寸与间隙不变；组列磁贴同步加虚线框（`.panel-editing .group-entry-row`）。
- "移除快捷引用"叉叉的中心对称修复：与第十七轮星标同根因（Chromium UA `padding:1px 6px` + 安全溢出回退），`.shortcut-remove`/`.shortcut-extract` 补 `padding:0`，e2e 断言字形与圆心偏差 < 0.5px。
- **已写入规范** `docs/前端设计规范.md`（图标按钮必须显式 padding:0；角标布局；材质与动效规则），防止复发。

### 4. 快捷键徽标

- 编辑模式下，绑定了快捷键的项目磁贴（主栏+组列）、主栏工具钮（搜索/整理/设置）、目录页脚动作钮（打开当前目录/新建文件夹/复制地址/打开项目软件）右下角显示只读小徽标：Ctrl=C、Shift=S、Alt=A + 主键字符（如 Ctrl+Shift+Alt+C → `CSAC`）。

### 5. 软件内更新（新功能）

- 设置与备份页最底部新增"软件更新"卡片：当前版本、检查更新、更新说明、按安装方式提示（便携=下载校验后直接替换文件；安装=下载校验后重新安装）。
- 原生 `UpdateService`：GitHub Releases 查询、版本比较、资产挑选、下载（GitHub 域名白名单+逐跳重定向校验+600MB 上限）、同名 .sha256 资产强制 SHA-256 校验（不一致删除拒绝）、便携版经固定内容的 apply.ps1 退出-替换-重启、安装版直接运行安装程序。`update.check/download/apply` 三方法已记录进 `docs/内核接口协议.md`。
- **限制（需要用户决定）**：仓库 `sfex1320/luma-quick-launch` 当前为**私有**，软件内检查更新只有在仓库转为**公开**后才能匿名工作；本功能按公开后可用的完整流程实现，私有时给出明确错误文案。v0.4.0 的 ZIP/EXE/SHA256 已作为预发布资产上传到该仓库（与既有 v0.3.4 等一致）。

### 6. 面板材质修复

- 根因：`.overlay-dock .glass` 的通用背景覆盖了一切材质类 → 子菜单材质从未生效，实色下木纹透入明显。
- 修复：材质背景按材质类+明/暗主题+overlay/非 overlay 全组合定义（styles.css 末尾）；实色=微透（约 96% 不透明、无模糊），强磨砂=blur(28px) saturate(140%) + feTurbulence 低对比颗粒层，清透=blur(12px)。明暗两种主题全部定义，e2e 双主题断言。
