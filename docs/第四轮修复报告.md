# 第四轮：目录浏览、图标成组与完整滑动

日期：2026-09-19。针对本轮用户反馈，直接修复当前 React / WebView2 / Windows 宿主；保留已有配置和视觉体系。

## 根因与修复

1. 原动效只有 12px 位移，同时每帧将动画中的坐标同步给原生 SetWindowRgn，导致裁剪与动画相互追赶。现为完整屏外进入、360ms 入场 / 300ms 退场、单个合成动画；首次等待原生显示确认，反向从当前帧接续。固定局部扫过区域覆盖窄面板下更宽的堆叠和阴影，不占整屏。
2. 原长按只显示 `project.items.slice(1)`，单文件夹根本没有读取磁盘。现单目录读取真实一级内容，目录优先、自然排序；子目录右侧箭头继续浏览，返回、刷新及打开当前目录均可用。组合展示全部保存入口，包含第一个默认入口。
3. 目录/组内条目统一使用指针捕获：按下不启动，滑选松手才启动，移出取消。Esc 清除计时；旧目录打开结果不关闭新菜单。
4. 浮岛右侧铅笔进入整理模式，图标拖叠可组合软件、文件夹或混合入口。主栏与“更多”双向拖叠；组合保留目标默认入口和顺序，按路径去重；可拆分。仅更新引用，不移动或删除真实文件。组合图标采用四宫格与数量角标。
5. 原生目录请求最长 4 秒，原本持有整个消息队列，能阻塞窗口退出确认。现目录读写独立调度且全局有界，保存及 window.sync 继续顺序处理；窗口关闭后丢弃迟到响应。

## 使用

- 长按文件夹约 300ms：显示其内部目录和文件。长按滑到目标松手打开；移出松手取消。
- 子目录右侧箭头用于继续浏览；底部“打开当前目录”在资源管理器中打开。
- 点右侧“整理图标”→拖一个图标到另一个图标上→“完成整理”。展开组合后可“拆成独立图标”。
- 每组可绑定至多 200 个入口，可以超过 5 个目录；整个配置至多 100 个图标。

## 协议与范围

最小新增 `folder.list` / `folder.open`，protocol=1 和状态 schemaVersion=1 不变。根目录从保存入口解析，前端后续只传客户端/根绑定的短期令牌，启动前重验。每次最多枚举 201 / 返回 200 项并提示截断；不递归，不全盘扫描。链接/联接点不穿越，目录内 .lnk/.url 需将真实目标另存为快捷入口；已保存软件快捷方式原有启动路径不受影响。
