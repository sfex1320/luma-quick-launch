# 第十一轮实现与验收报告

日期：2026-09-21。版本：0.3.1 候选测试版。源码完成本轮功能实现和自动化回归；尚未替换用户正在使用的 0.3.0 APP。本文不将浏览器模拟或原生单元测试等同于真实 Windows GUI 验收。

## 修复与实现

| 用户问题 | 本轮行为与原因 |
| --- | --- |
| 出现打开/进入后无法长按 | 未分割区域、左右分割按钮均支持持续长按；保留指针捕获和父级菜单，布局变化不会误打开新目标；移出松手取消 |
| MOMO 无测试入口 | 根目录没有 test，但有明确 Tauri 开发配置；自动顺序为已保存手动覆盖、test、明确 Tauri、dev、start。MOMO 对应 pnpm run tauri dev；识别不执行、不安装依赖。真实终端运行仍待原生验收 |
| 测试按钮位置 | 在当前目录底部的“打开当前目录”右侧显示“测试软件”或“打开项目软件”，保留实际命令说明 |
| 合并冲突、设置与浮岛不同步 | 修复同一事件周期的旧状态读取、保存中的再次编辑、暂停期间状态消息丢失；按 revision 重放最新状态，恢复时主动重新读取；真正同字段并发冲突仍保留本地修改并提示重新载入 |
| 拖拽成组与排序 | 卡片/图标中心合并引用，边缘插入排序并显示插入提示；编辑模式 X 移除引用，组内成员可移到主面板或其他组；保留进入子菜单按钮 |
| 过宽后无法操作 | 初始宽度不变，随一级入口增加到 1120/屏幕上限，之后横向滚动；工具按钮固定右侧；右键拖动横向滚动顶栏、纵向滚动目录，静止右键显示菜单 |
| 软件最近项目 | 软件提供“打开软件/最近”分割入口及长按入口，可设 6–10 条，显示完整文件位置；父集合与最近列表并列显示并限制在屏幕内 |
| 软件窗口复用 | 保留完整路径/安全身份匹配与最小化恢复，进一步核对实际前台 HWND；找到窗口但 Windows 拒绝前置时也不重新启动副本。真实 Photoshop 前置需物理回归 |
| 搜索 | 可选软件别名 AI/PS 等，目录/文件名使用更保守的模糊规则；本轮模糊匹配针对已保存入口，Windows 索引查询继续原有范围，不全盘扫描 |
| 网址收藏 | HTTP(S) 文本可拖入主面板或集合，读取网站标题与安全静态图标，允许改名和备注；网络失败保留域名入口。网站信息获取只在添加/编辑时发生 |
| 文件集合 | 任意已有文件按路径引用添加与打开；合并、拆分、移除均不复制、移动或删除源文件 |
| 右键与真实目录 | 按上下文提供打开、进入、复制地址、整理/移除引用，真实目录额外提供新建文件夹、重命名、准备移动/移动到此目录 |
| 文案与对齐 | 移除“组内入口仅保存引用”说明，拆分按钮与打开默认入口同行 |

保留既有 650ms 推出、600ms 收回曲线。未增加后台动画、全盘递归或逐帧原生命中区同步。最近项目、网站检查和目录 IO 均不阻塞 window.sync 消息队列；新增三项回归先复现阻塞，再修复。

## 引用和实际文件的边界

1. 顶栏、设置、集合的拖入、合并、排序、拆分、X、移除快捷项，只修改配置引用。删除引用不会删除磁盘文件。外部 Explorer 文件拖入这些位置也只保存引用。
2. 在真实目录菜单选择“新建文件夹”或“重命名”才写磁盘；界面明确提示真实文件操作并提交名称，不接受任意路径。名称禁止穿越、Windows 保留名、同名覆盖和重解析点绕过。
3. 实际移动使用真实目录条目的临时令牌，拖到专用“移动到当前实际目录”区域或右键准备移动，再确认目标。普通图标拖拽不推断为磁盘移动。
4. 当前实际移动仅支持软件已列出的真实条目，在同卷的已绑定目录之间操作；不提供跨卷复制后删除，也不把 Explorer 外部文件拖放自动转换成真实移动。该边界避免在整理快捷项时误动项目文件。
5. 真实文件没有“删除磁盘文件”菜单。遇同名冲突不覆盖；部分成功返回明确计数与错误并刷新令牌。磁盘提交开始后前端等待实际结果，不在八秒后误报失败并允许重复提交。

新增文件写入测试只操作独立临时夹具，没有拿用户实际项目演练。

## 必须如实保留的限制

- **内存目标未达到。** 用户目标闲置 50–100 MB、互动不超过 150 MB。现用 0.3.0 的只读快照 eleventh-resident-check.json 中，宿主及所属 WebView 共 7 进程，私有内存 493842432 bytes（约 471 MiB）、4401 句柄。单点不是泄漏斜率或纯闲置基线，更不是本候选实测。不能只报宿主或排除 WebView 来宣称达标。
- **CPU 目标未验收。** 单点快照没有可用 CPU 区间；不得据此承诺闲置 0% 或互动始终低于 3–5%。整机 DWM 单独记录，不能全部归因 Luma。
- **五小时未通过。** 旧冻结版本只运行 6503.4 秒后因 DWM 保护停止，不能算连续 18000 秒，也不能证明本候选稳定。保护、休眠、退出、断档均使连续验收失败。
- 当前 WebView2 生命周期虽暂停后台页面，但不会释放整个 Chromium 运行时。达到 100/150 MB 需要独立评估销毁重建或原生浮岛方案，并同时验证唤出延迟；本轮没有静默替换现有框架。详情见 r11-runtime-review.md。
- 最近列表来自 Windows Recent 的最多 256 个枚举样本，再按软件明确格式与时间筛选，可能遗漏较新的记录；它不是 Photoshop 等软件私有历史数据库，未知软件可能为空。打开遵循 Windows 默认文件关联。
- 网站 favicon 只保留受限静态 PNG/ICO，SVG 等不解析；网络/格式不支持时保留通用网站图标。请求拒绝本地/私有网络抓取和重定向绕过；用户保存的网站链接仍可正常通过 Shell 打开。
- 真实文件 Explorer 外部拖入实际目录移动、跨卷移动、全索引拼写纠错、所有软件私有最近项目均未宣称支持。
- 仍缺受信任签名证书、其他 Windows 实机验收，不发布为正式稳定版。

## 剩余原生验收与交付顺序

用户现用 APP 运行时只做只读观测，不停止、不打开第二原生 GUI、不改用户配置。退出且前台非全屏时，使用唯一独立候选副本及独立配置继续：

1. 标准 native/system/lifecycle 与安装、升级、卸载；最后打包后仍需对实际解压产物验证。
2. 双屏长按左右按钮/逐级菜单/移出取消、收回途中切换窗口/最小化/Alt+Tab/鼠标返回、暂停后跨窗口配置同步。
3. 真实 OLE 文件/网址导入、集合内外引用拖拽、右键拖动滚动、实际文件临时夹具重命名/新建/移动冲突。不得用用户项目测试写入。
4. 拖入无依赖 Node 仓库，验证自动/手动入口、cwd、可见终端输出、一次执行与去重、清单变更重新识别；MOMO 本仓库只做经用户明确点击的测试运行，不自动安装依赖。
5. 真实软件窗口复用/最小化恢复和最近文档；不同 Windows Shell 缩略图格式与网络失败回退。
6. 收起浮岛+设置最小化连续 18000 秒，逐进程角色/CPU/私有内存/句柄、系统响应性与 DWM；不要抬高保护阈值或把低于阈值当无泄漏。无 Luma 时另测 DWM 基线。

必要验收通过后才按已有授权更新 APP、便携 ZIP 与安装 EXE、发布 GitHub 新版本测试 Release；不改写历史 0.2.0 Release。当前正在使用的 0.3.0 及用户配置保持不动。
