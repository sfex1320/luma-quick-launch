# 第七轮交付：Luma Quick Launch 0.2.0

用户要求便携包与安装版，桌面快捷方式、软件内开机启动，并确认面板只需要在普通窗口上方，不额外申请管理员权限。

## 使用

- **便携版**：完整解压 ZIP，运行 `Luma.exe`，或双击 `Start-Luma.cmd` 打开设置。程序需要同目录依赖，不能只复制一个 exe。
- **安装版**：运行 `luma-quick-launch-0.2.0-setup-x64.exe`。默认安装至当前用户 LocalAppData/Programs，创建桌面与开始菜单入口，提供卸载功能。
- **桌面入口**：两版都能在“设置与备份 → 启动与桌面”创建快捷方式。已有无关同名快捷方式受到保护，不覆盖。
- **开机启动**：同一卡片内开启/关闭，默认关闭。登录后在托盘待命，软件内显示 Windows 实际状态；配置导入不会启用开机启动。移动便携目录后重新创建系统入口。
- **层级**：保留 Topmost 与全屏避让；asInvoker、uiAccess=false，不改变其他程序的置顶属性。

## 实现与验证

- protocol=1 新增三项系统方法，详见内核接口协议文末；项目 state schema 与 CAS 不变。
- 桌面链接只指向实际当前 exe；HKCU Run 引号与参数固定，关闭/卸载只删除当前副本拥有的值。
- 安装升级保持当前开机启动与 Windows 禁用状态，卸载保留用户配置。精确 exe 路径退出事件避免关闭另一份 Luma。
- 发布前：27 前端单元、57 Edge E2E、240 内核单元通过；最终解压程序的真实桌面/启动项 8 项、独立生命周期 4 项、标准原生回归 18 项通过。最终安装器的真实安装/升级/卸载 28 项通过，294个安装文件与同一便携载荷逐个哈希一致。
- 独立审查发现并修复安装器同名快捷方式覆盖、生命周期测试误关既有实例两项问题；复审无剩余发现。
- `scripts/package-release.ps1` 验证完整解压产物与真实系统入口；`scripts/build-installer.ps1` 从同一产物生成安装器；`native/tests/installer-smoke.ps1` 实际安装/卸载并恢复测试前系统入口。

## 分发边界

两版均包含 .NET 运行时、前端和第三方许可证，不含用户配置。需要 WebView2 Runtime，程序暂未签名。当前测试平台为 Windows 11 x64 双屏；不承诺未经验证的平台行为。真实桌面 Acrylic 背景模糊仍未启用。
