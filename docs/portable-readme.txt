Luma Quick Launch 0.3.3 — Windows x64 便携测试版

1. 完整解压压缩包到固定目录，不要在压缩包内直接运行。
2. 直接双击 Luma.exe 启动软件；Start-Luma.cmd 可直接打开管理窗口。
3. 拖入文件夹、软件快捷方式或文件，建立快捷项。
4. 鼠标悬停在任意显示器顶边居中位置，唤出快捷面板。
5. 单击打开；长按展开，滑到目标后松手打开，移出取消。
6. Ctrl + Alt + Space 打开独立搜索；托盘菜单可打开设置或退出。
7. 在“设置与备份 → 启动与桌面”点“创建桌面快捷方式”，以后双击桌面图标即可打开。
8. 同一区域可开启/关闭“开机启动”；默认关闭，登录 Windows 后在托盘待命。
9. 浮岛显示在普通窗口上方，不申请管理员权限；全屏避让保持启用。

运行条件
- Windows 10 22H2（19045）及以上 x64；当前实际测试为 Windows 11 双屏，其他系统尚未实机验证。
- 已包含 .NET 运行时，使用者不需要安装 Node.js 或 .NET SDK。
- 需要 Microsoft Edge WebView2 Runtime。如果提示缺失，请从微软官网安装：
  https://developer.microsoft.com/microsoft-edge/webview2/

配置与升级
- 配置保存于 %LOCALAPPDATA%\Luma，不在本压缩包中。
- 原位置升级：先退出旧版，将包内全部程序文件覆盖到原程序目录，再启动；不要只替换EXE。
- 覆盖不会删除 %LOCALAPPDATA%\Luma 中的项目配置；升级前可在设置中导出备份。
- 请保留整个程序目录；不要只移动 Luma.exe。
- 移动便携版目录后，请重新创建桌面快捷方式，并重新开启开机启动以更新路径。
- 安装版另提供 Setup.exe，含开始菜单、桌面入口和卸载功能。

本版新增
- 统一顶栏标签字号与基线，避免裁切；目录底部操作同一行，新建/复制支持长按滑选松手。
- 修复开发入口被强制离线导致MOMO的ONNX链接失败；开发启动沿用用户环境，项目脚本可能按其配置获取依赖。
- 打开/进入分割按钮均支持长按；修复快速成组和设置到浮岛的状态同步。
- 拖到图标中心合并引用，边缘调整顺序；编辑模式可移除引用、移入/移出集合。
- 顶栏达到宽度上限后横向滚动，右键拖动滚动，静止右键显示操作菜单。
- 软件最近项目可设6至10项；Photoshop、Illustrator、InDesign读取各自软件最近记录，其他软件暂未接入。
- 支持HTTP(S)网址收藏、网站标题/静态图标、改名备注、软件别名及已保存名称模糊搜索。
- 自动识别已有test、明确Tauri开发入口、dev/start，打开项目软件按钮位于打开当前目录右侧。
- 文件夹可填写手动CMD启动命令与工作目录，保存不执行，可恢复自动识别。
- 文件图标内静态缩略图；图片、视频、PSD/CDR/AI支持取决于系统Shell缩略图处理器。
- 持续长按逐级展开，保留父菜单；悬停显示打开/进入大点击区。

测试版说明
- 功能测试已通过，但连续5小时稳定性尚未通过；旧冻结版本曾触发DWM保护停止。
- 本版按用户要求先行覆盖交付，不代表系统级卡顿已经彻底解决。
- 总运行时内存闲置50至100MB、互动150MB的目标尚未达到，CPU目标仍需实测。

功能边界
- 合并、排序、拆分、移除和普通文件拖入只修改快捷引用，不移动或删除源文件。
- 只有明确的真实目录新建、重命名和确认移动才修改磁盘；移动仅同卷、禁止同名覆盖。
- 实际移动使用本软件列出的文件令牌；外部文件普通拖入不会变成真实磁盘移动。
- 文件与正文搜索依赖 Windows 索引，不自动扫描全盘。
- 已打开的普通文件夹和可安全识别的软件窗口会优先恢复并前置。
  带参数的快捷方式和文档保留系统原有打开方式，不能保证所有软件均可复用。
- 浮岛使用前端玻璃样式，尚未启用真实桌面 Acrylic 背景模糊。
- 程序未签名，首次运行可能显示 Windows 安全提示。

第十三轮快捷键与抓手
- 设置与备份 → 快捷键：选择功能、项目组或组内入口，录制按键后添加。
- 单键仅点击浮岛、获得焦点后有效；Ctrl/Shift/Alt组合可选择全局。输入/对话框期间不运行面板快捷键。
- 录制时全局键暂时暂停，结束后恢复；如被其他软件占用会显示失败，可移除后重新绑定。
- 当前目录打开/新建/复制/项目运行可绑定面板键，操作最深层目录；新建仍先确认名称。
- 子菜单空白处左键抓手上下拖动，主栏保持右键横拖；软件成组仅“进入”，去掉图标下拉角标。
