# 第四轮：组合与拆分实现记录

2026-09-19。范围：`src/core/groups.ts`、`src/components/GroupIcon.tsx`、独立 `group-icon.css`、`src/App.tsx` 与对应测试；浮岛手势由主任务在 Dock 集成。

## 根因与实现

- 现有卡片拖动只执行排序，没有合并或拆分数据操作。保留该排序交互，项目页新增「合并到其他图标…」与「拆成独立图标」。合并对话框明确目标保留名称、颜色、置顶状态、默认入口，来源入口追加。
- 旧 `ItemIcon` 的 `stack=true` 把软件组合画成文件夹。新增 `GroupIcon`：单入口按真实类型显示，多入口显示最多四个真实类型缩略图和数量。用于速览、管理卡片及待主任务接入的浮岛。
- `mergeProjects` 不更改目标项目 ID、名称、描述、颜色、置顶状态及原成员順序；按大小写不敏感、统一 Windows 路径分隔符和尾部分隔符去重。来源项目只在全部去重与容量检查成功后移除。保留成员 ID，仅在目标内冲突时分配唯一 ID。
- `ungroupProject` 原位替换组，首成员保留原项目 ID，其余成员分配唯一项目 ID；所有成员保留入口 ID、路径、名称、类型，继承原组颜色和置顶状态。图标名称使用成员名称（项目名限制 60 字，入口名仍完整），首成员保留原描述。
- 单组上限 200、工作区上限 100；溢出整次拒绝，输入不变。最终 `StateSchema` 校验通过后才提交状态，revision 由现有 `useWorkspace` expectedRevision/CAS 保存流程管理。
- UI 错误捕获与冲突保护：冲突时阻止后续组合/拆分；同事件中的操作使用当前工作区引用。操作只更改快捷引用，不调用启动、移动、删除文件功能。
