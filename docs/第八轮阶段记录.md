# 第八轮阶段记录：0.3.0 候选版

更新：2026-09-21。本文件明确区分实现、实测与尚未完成的交付；不是正式版验收证明。

## 已实现

- 纯绿色玻璃叠片 Logo，无文字/字母；设置品牌、加载页、网页图标、EXE/托盘/安装器共用九档 ICO。
- 当前保存宽度作为初始宽度，按置顶顶层入口数扩展与回缩，最大1120且不越出屏幕；分组内部入口不影响宽度，超额仍进“更多”。220ms横向变换过渡，保留650/600ms纵向滑动。
- Windows10 22H2 build19045+ x64技术目标；打包 Microsoft 签名 WebView2 在线引导安装器，缺失时当前用户安装；失败有界处理。实际平台/生命周期边界见 Windows兼容与依赖.md。
- 设置/搜索最小化及浮岛完全收起后暂停 WebView；恢复先唤醒；导航后核对真实 IsSuspended，避免缓存误判。渲染故障限频恢复，严重故障停止循环且保留配置。
- 签名接入脚本、实际签名验真与升级/回退文档已补；本机没有发行者受信任证书，**仍未签名**，不冒充已完成。

## 已有实测

- 前端单测30/30、完整Edge E2E63/63；原生单测263/263；Release自包含构建通过。
- 复制真实用户快捷项到隔离配置，设置最小化短测确认设置/浮岛暂停，私有内存约427→405MB（61.5s），配置哈希未变。
- 独立renderer故障短测验证重新加载、fresh布局与再次展开；不作为5小时通过证据。
- DWM在当前权限下Get-Process.CPU不可读；早期短测中的DWM=0已撤回。改用Windows只读原始性能计数器，之后短测可取得DWM值；它是整机合成器数据，不能全部归因于Luma。GPU显存尚无有效采样。

## 尚未通过的验收

- 用户报告的5小时最小化挂机卡顿尚未完成同等时长验证，根因未被完全证明。暂停处理修复确定的后台行为缺口，不能直接宣称解决所有系统卡顿。
- 当前原生全套交互回归未通过：一次收起检查超时；最新重跑在全屏UnrealWindow触发正确避让后无法展开。保留原测试断言，待桌面可测条件恢复重跑；不关闭用户游戏、不绕过全屏保护。
- 最终ZIP/安装EXE的native/system/lifecycle/安装升级卸载需在代码冻结和环境可测后完整运行。当前候选目录不能冒充最终发布包。
- Windows10、干净Windows11、ARM模拟和企业策略/离线环境暂无实际机器证据；签名证书依赖发行者身份与证书配置。

使用 `native/tests/Reliability-Soak.ps1 -Seconds 18000 -SampleIntervalSeconds 30 -RevealEverySeconds 0 -UseUserState`；独立程序完整副本、独立配置，设置最小化，低频采样整棵进程树内存/句柄/CPU、系统可用内存、DWM及窗口响应性。超过内存/增长/句柄阈值或持续CPU、DWM、无响应时停止测试；长采样断档/系统休眠不算完整通过。
