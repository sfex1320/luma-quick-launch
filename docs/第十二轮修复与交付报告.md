# 第十二轮修复与交付报告

2026-09-21，目标版本0.3.2。用户要求完成后直接覆盖现用程序和所有原交付便携包、安装包，桌面快捷方式继续启动现用便携目录。

## 修复

- 顶栏folder/app/group的图标占位不同，原flex压缩文字造成基线相差6.4px及下缘裁切。现统一图标方形占位、12px字号、18px完整文字行，保留原650/600ms动画与玻璃风格。测试覆盖64/88/160高度、24/40/64图标、窄屏/深色；已写入前端设计规范。
- 系统卡片“查看操作指南”原左边距只有1px，现同其他内容保持14px内缩。
- 目录底部四个文字操作共享一行；新建和复制加入同一长按手势分发，滑入松手只执行所选操作，不误开目录。窄屏横向滚动不换行。常驻命令/计数/滑选备注删除，实际移动改同行专用小图标，仍明确确认后才写磁盘。
- MOMO启动失败根因：Luma原对全部自动命令注入CARGO_NET_OFFLINE=true，ort-sys因此跳过ONNX依赖获取并输出link_error_generic/OrtGetApiBase链接错误。开发入口现继承用户环境，仅点击后执行项目既有命令；test入口仍离线，manual不变，不替用户额外运行install/fetch或cargo clean。
- 同指纹重新识别的taskId现在刷新两分钟有效期，避免刚展开就过期；清单变更/目录/客户端绑定仍重验。
- Photoshop、Illustrator、InDesign各自读取Adobe MediaBrowser MRU；校验实际软件版本资源、逐项最多256次注册表读取、字符串预检类型/字节数，排序去重并限制6–10条。打开前重新验证。其他软件暂无可靠来源时说明未接入，不伪装成真实软件历史。

## 边界

不承诺所有软件私有MRU均已接入，Adobe本地MRU也不含未写入记录的云文档；枚举样本可能遗漏更近记录。字体长名称使用单行省略和title，不以缩小不同项字号适配。新建只进入命名确认，复制不改文件，真实移动仍不覆盖、同卷限定；未增加后台轮询或装饰动画。

50–100MB闲置/150MB交互内存目标和五小时稳定性仍未通过，不能以这次功能回归替代；仍缺受信任签名和其他Windows实机。交付所需实际解压包/native/system/lifecycle、专项原生和安装升级卸载、桌面快捷方式检查及最终版本/哈希将在下文补充。
