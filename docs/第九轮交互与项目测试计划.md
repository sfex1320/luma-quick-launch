# 第九轮：收回重入与项目测试入口

## 用户场景与约束

收回途中切换/最小化其他窗口不应重新呼出；真正重新进入顶边或浮岛的鼠标交互仍应有效。保留推出 650ms、收回 600ms 的完整滑移动画及 visibilityId 防过期语义。

绑定代码仓库后，在目录长按面板的“打开当前目录”旁提供“运行测试”。读取当前目录的明确项目清单，不递归扫描，不在拖入、保存、识别时执行代码。点击才打开终端，运行项目已有测试命令；不安装依赖、不自动选猜测的启动脚本。

现有协议没有项目测试能力。最小新增 protocol=1 方法：`project.detectTest {projectId,itemId,folderId}` 返回 `{task: {id,label,command}|null}`；`project.runTest {projectId,itemId,taskId}` 返回 `{opened:boolean}`。folderId 必须来自同客户端 folder.list；taskId 为短期绑定目录与清单内容的宿主令牌。前端不能提交路径、脚本或命令。清单变更需重新识别。优先支持 package.json 显式 test（尊重锁文件）、Cargo.toml、go.mod，以及明确测试项目的 .NET；无法确认时不显示按钮。

3. 前端与整合：协议、模拟桥、长按面板按钮、错误反馈、E2E；最终独立审查。
