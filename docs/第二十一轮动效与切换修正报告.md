# 第二十一轮动效顺序与切换抖动修正

2026-09-23 · **0.4.3** · 交付源码 `b174585dc45c675f05694e1da1e0ec0c920e32a1`

## 本轮用户确认的行为（覆盖第二十轮收起顺序）

- **弹出保持不变：一级先，二级后。**
- **收起改为：二级全部收回，再收一级。** 二级按速度档200/160/120ms，一级仍为600/450/320ms；没有二级时一级直接收回。
- 已打开状态切换文件夹或组，二级菜单直接换内容，不重播滑动。

## 根因与修改

1. 上轮错误地将弹出和收起设为相同次序。本轮为一级收起动画增加二级时长的等待，取消二级收起的等待；仍独立控制两层并等待两层结束后才collapsed，保留回收重入命中区域。
2. `menuKey` 变化会重新执行子菜单动画 effect，即使位置是0也创建新的一段有时长动画。现在区分“切换内容”和“显示/隐藏”：已打开状态切换时直接提交0位移，不等待一级、不重播滑入；首次展开、整栏重新唤出和当前帧反转保留原路径。
3. 新目录在原生列举返回前只有很小的加载提示，面板会先缩小再撑开。旧实现测试复现高度突变205.40625px。加载期间保留218px网格+45px动作行的空间，仍服从短视口flex收缩；不复用过期目录令牌、不提前启动或扫描目录。
4. README和前端规范已更新，package-lock顶层遗留版本号同步为0.4.3。
