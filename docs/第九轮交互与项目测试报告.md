# 第九轮：收回循环与项目测试入口

更新：2026-09-21。此轮已实现并构建候选程序，真实 Windows 全套交互验收仍待进行。不能当作已更新用户安装版本或正式发布。

## 窗口关系与收回问题

浮岛、设置与搜索分别拥有自己的原生窗口和 WebView 页面，不依托其他软件页面。WebView2 浏览器/GPU资源和 Windows 桌面合成仍可共享；切换窗口会产生焦点、鼠标及全屏状态事件。

查到并修复两条重入路径：

1. EdgeActivation 的关闭检测与 App 的1400ms兜底都将全局 Alt/Win/鼠标按键视为 CancelClose。因此操作其他窗口也会逆转已经开始的收回。改为全局按键仅延迟尚未开始的自动收回；Closing 只接受真实浮岛交互/鼠标返回。
2. Dock 的普通 pointermove 在 visible=false 时自行显示，未区分原生事件。原生模式由宿主判定真实重入，前端不再用该事件私自改变显示状态。

保留推出650ms、收回600ms、完整纵向滑移、opacity=1、当前帧反转及 visibilityId 防过期规则，没有重做动画曲线或加入弹跳。修复前原生回归5项失败，前端回归也成功复现退出被逆转；修复后通过。

## 项目测试怎么使用

将仓库文件夹作为快捷入口保存，长按展开。当前目录有明确测试入口时，“打开当前目录”旁出现“运行测试”，下方显示命令。支持点击、长按滑选后松手和键盘操作；移出取消。项目仍可像普通文件夹一样查看一级文件及进入子目录。

|项目|识别条件|执行命令|
|---|---|---|
|Node|package.json 明确 scripts.test；packageManager/锁文件一致|npm、pnpm 或 yarn run test|
|Rust|Cargo.toml 包或工作区|cargo test --offline|
|Go|go.mod 的 module 声明|go test ./...|
|.NET|当前层唯一明确的 IsTestProject=true 测试项目|dotnet test 对应csproj --no-restore|

没有测试脚本、多种候选冲突或不支持的项目不猜命令；Python、自定义批处理与 dev/start 不在本轮范围内。测试工具需已经安装，依赖需已准备；Luma不会替用户安装或恢复依赖。用户测试脚本自身的行为仍遵循项目和测试工具语义。

识别只读取当前目录、不会运行代码。前端只能提交已保存入口和短期令牌。宿主执行前重新校验目录、清单/锁文件哈希与客户端；清单变更/令牌过期提示重新展开。读取有界、慢IO不占布局消息队列，也不持UI共享锁。重复点击同目录不会新开终端；提示使用已开的测试终端，关闭后可再次执行。终端保留输出与退出码。

项目检测和运行失败时保留目录内容。晚到的响应不能关闭用户新打开的目录。200项长目录下优先让格子滚动，极矮窗口允许整个二级面板滚动，底部按钮可达，格子尺寸仍为88×94。
