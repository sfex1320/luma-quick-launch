# 第七轮：便携版、安装版与系统入口

用户已要求便携包和安装 EXE，并确认“面板权限较高”指普通窗口上方，不提升管理员权限。本轮版本 0.2.0，沿用 React + WPF/WebView2 与 protocol=1。

## 约定

- 便携 ZIP 内直接运行 Luma.exe，应用内提供创建桌面快捷方式和开机启动开关。
- 安装版使用 Inno Setup，为当前用户安装，不申请管理员权限；桌面/开始菜单入口与卸载功能齐全，升级和卸载默认保留用户配置。
- 开机启动默认关闭；读取操作系统实际注册状态，不混入可导入/导出的 preferences，不因配置导入而启用启动项。
- 快捷方式和启动项只指向当前程序的真实 exe，不接受前端路径或命令。快捷方式打开设置，登录启动仅驻留托盘。
- 多份程序共用一个用户启动项；开启当前副本明确替换目标，关闭时不误删另一副本的注册。前端说明移动便携目录后需要重新创建系统入口。
- 保持浮岛位于普通窗口之上，保留全屏避让；不改变目标软件的 Topmost，不使用管理员清单。

## protocol=1 最小补充

现有方法不能表达系统入口操作，因此新增以下三项，不改变已有方法/字段。系统状态结果统一为 `{ autoStart: boolean, autoStartHere: boolean, desktopShortcut: boolean }`。

- `system.getIntegration`，参数 `{}`：读取启动项是否存在、是否指向当前 exe，以及桌面快捷方式是否指向当前 exe。
- `system.setAutoStart`，参数 `{ enabled: boolean }`：开启/关闭当前 exe 的用户启动项，返回实际系统状态。失败使用现有错误码和可读反馈。
- `system.createDesktopShortcut`，参数 `{}`：创建指向当前 exe 的桌面入口，返回实际系统状态。
