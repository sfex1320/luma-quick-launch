# 第十一轮：交互、引用集合与真实目录

用户已授权实现本轮需求。保持 protocol=1、现有框架、650/600ms 滑动曲线；不修改当前运行的 APP 或用户配置。实现和回归在源码与独立测试夹具中进行。

## 操作边界

| 位置 / 操作 | 结果 | 是否改磁盘 |
| --- | --- | --- |
| 顶栏、设置卡片：拖到图标中心 | 合并快捷引用 | 否 |
| 顶栏、设置卡片：拖到图标间隙 | 调整快捷引用顺序 | 否 |
| 集合内入口拖出、拖入，X / 移除快捷项 | 调整或删除引用；空集合消失 | 否 |
| 外部文件、文件夹拖到顶栏 / 集合 | 保存路径引用，不复制文件 | 否 |
| HTTP(S) 网址拖入 | 网站收藏引用，可重命名 / 备注 | 否 |
| 真实目录菜单：新建文件夹 / 重命名 | 对已验证目录令牌执行，名称禁止路径穿越、覆盖与保留名 | 是，明确标注 |
| 真实目录：移动到此目录 | 独立明确入口与目标确认；普通拖入仍只存引用 | 是，绝不覆盖同名文件 |
| 打开 / 复制地址 / 最近项目 | 打开或复制已保存 / 已授权目标；不删除源文件 | 否 |

不提供含糊的“删除文件”：集合中使用“移除快捷项”；真实文件不提供磁盘删除。本轮真实文件操作只在临时测试目录验证，不拿用户项目试验。

## 实现顺序与验收

1. 修复分割按钮长按，完整保留捕获来源与父级菜单；松开当前目标才打开，移出取消。左右按钮都可持续长按。
2. 修复多窗口状态同步与快速连续拖拽；中心合并、边缘插入；整理模式可移除、移入、移出。对真实并发冲突保留本地修改，不静默覆盖。
3. 查明 MOMO 根目录识别；自动识别已有启动脚本，手动命令优先；启动按钮紧邻“打开当前目录”右侧。仅执行重新验证后的能力令牌，禁止恢复依赖。
4. 最大宽度保持 1120 / 屏幕可用宽度；顶栏横向滚动、子菜单纵向滚动；右键拖动超过阈值取消右键菜单。加入上下文菜单。
5. 网址收藏、保守模糊搜索与软件别名；软件最近项目最多 6–10 条，显示真实位置，不承诺读取所有软件的私有历史库。
6. 真实目录操作单独能力校验与测试；通过清晰界面区分引用和磁盘。
7. 资源与稳定性审查：计算宿主及自身 WebView 总开销，排除通过它启动的 Photoshop 等应用。150MB 是用户目标，必须实测，不能把宿主内存当作总内存；五小时持续验收仍未通过。
