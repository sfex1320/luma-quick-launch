## 已完成的前端

| 范围 | 验证 |
|---|---|
| React/TypeScript 生产构建 | npm run build 通过 |
| 布局约束 | 正常尺寸、窄视口、文字放大测试 |
| 长按 | 单击主目录、长按取消短按、滑选目标、外部取消测试 |
| 数据边界 | 重复 ID、非法尺寸、空主目录、无效事件/响应拒绝 |
| 项目管理 | 新建、修改、目录入口、置顶、排序、移除、搜索 |
| 外观 | 宽高、图标、圆角、预设、材质、深浅主题、减少动画、重置与撤销 |
| 保存 | 合并保存、JSON 导入导出、重载恢复、保存错误提示 |
| 浏览器 E2E | 长按选中、取消、新项目持久化与搜索、尺寸溢出与主题、原生缺失报错、窄视口 |
| 宿主模拟 E2E | 保存回声兼容、透明根背景、局部热区、动画最终区域、搜索原生路由 |

执行结果：`npm test` 3 个文件、12 项测试通过；`npm run test:e2e` 8 项测试通过。构建 JS 约 356 KB、gzip 约 109 KB，CSS 约 35 KB；这是交付文件体积，不是运行内存。

浏览器截图保存在 `docs/previews/`：workspace.png、stack.png、dark.png、compact.png。截图用独立无头上下文生成，不是设计稿冒充实现。

## 审查与已修正问题

独立只读审查指出：原生保存回声可能误判冲突、HTML 根背景未透明、动画后的命中矩形未重算、顶边热区报成整行、Ctrl+K 未走原生搜索路由。对应修复已加入，并以宿主模拟回归测试验证。

## 仍属于原生内核工作

- 真实 Windows 顶边热区、全屏避让、不抢焦点、透明区域穿透。
- 操作系统 Acrylic 与区域裁剪。CSS 只能模糊页面内容。
- 本地目录/文件/应用启动、系统选择文件夹、网络路径与权限错误。
- 原子文件存储、备份恢复、多窗口配置同步的真实进程实现。
- 系统托盘、单实例、多屏、DPI 与系统文字设置联调、安装包。
- 整体进程树的 CPU、内存、GPU 与 DWM 增量实测。

宿主模拟测试证明前端可以按协议交互，不证明上述 Windows 能力已完成。

## 首版前端范围之外

尚未提供跨项目拖拽、实时目录树、已开资源管理器窗口/标签关联、路径修复向导、原生开机启动。项目样例路径都是演示；浏览器会明确显示“未访问真实文件”。

## 复验

```powershell
npm ci
npm run build
npm test
npm run test:e2e
```

E2E 默认使用已安装的 Edge；预览服务器仅监听回环地址。`node scripts/generate-contract.mjs` 更新机器可读契约，`node scripts/capture-preview.mjs` 在 5173 开发服务器运行时更新截图。
