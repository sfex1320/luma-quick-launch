# 第十三轮：抓手、成组入口与快捷键

用户已授权实现及直接覆盖交付。单键仅 Luma 面板有焦点生效；组合键可全局。沿用当前前端与 protocol=1，不改650/600ms动效，不动用户文件与已有配置。当前代码分支为 codex/brand-compat-adaptive。

## 交互

- 主工具条保留右键水平拖动和静止右键菜单。
- 所有子菜单（组入口、真实目录各级、最近文件）的滚动区域支持左键空白抓手；7px阈值、抓手光标、捕获/失焦/取消清理，不干扰按钮与图标长按滑选、编辑拖拽、滚轮和文本输入。右键在子菜单恢复普通菜单，不用于拖动。
- 包含多个入口的软件组悬停仅显示全宽“进入”，无“打开”；单软件保留打开软件/最近。文件夹原有双按钮保持。
- 去掉图标右上角专用展开箭头，包括编辑态；通过悬停进入、长按或右键仍可展开，编辑X和移出集合保留。

## 最小协议补充

preferences.shortcuts?: ShortcutBinding[]，最多128条，不存在时行为与旧版相同。
ShortcutBinding = { id:string, code:string, ctrl:boolean, shift:boolean, alt:boolean, scope:'panel'|'global', action:'dock'|'search'|'settings'|'edit'|'project'|'item'|'openDirectory'|'newFolder'|'copyAddress'|'runProject', projectId?:string, itemId?:string }。
code采用KeyboardEvent.code：KeyA–KeyZ、Digit0–Digit9、F1–F24、Space/Enter/Tab/Escape、ArrowUp/Down/Left/Right、Home/End/PageUp/PageDown/Insert/Delete/Backspace、Numpad0–9、NumpadAdd/Subtract/Multiply/Divide/Decimal/Enter、Backquote/Minus/Equal/BracketLeft/BracketRight/Backslash/Semicolon/Quote/Comma/Period/Slash。
全局至少包含Ctrl/Shift/Alt之一；纯修饰键不接受。目录四操作只能panel范围，使用当前最深层的可用按钮/目录令牌，不保存瞬时目录token。project/item必须有projectId，item必须有itemId；其他action不得携带目标ID。重复按键组合（跨scope亦重复）拒绝；内置Ctrl+Alt+Space搜索与Ctrl+K预留，不允许冲突。旧入口被删除时绑定可保留为“目标已失效”，绝不能执行旧路径。

新增 shortcut.getStatus({}) -> { bindings: [{id, registered:boolean, message:string}] }，包含全局注册成功/占用/失效及面板内状态。
新增 shortcut.execute({id}) -> {accepted:boolean}：只执行当前配置中存在的绑定，供面板内dock/search/settings/project/edit及入口走同一后端路径；不接受临时命令/任意路径。四个目录动作由前端现有受验证目录按钮执行，不走execute。
新增宿主事件 shortcut.activated data:{id:string,serial:number}：只面向浮岛，用于打开已保存项目子菜单或整理模式；先唤出并等新布局可用后可靠发送，去重、不在设置预览重放。原生全局item直接使用已有有界启动服务和窗口复用，不依赖前端焦点。

## 快捷键交互

设置与备份页面增加快捷键管理卡片：动作/项目/入口选择、录制按键、作用范围、启用保存（复用app.saveState）与移除、注册状态。录制不触发动作；焦点在input/textarea/select/contenteditable或有对话框时面板快捷键暂停，IME/repeat跳过；原生全局用MOD_NOREPEAT。global在原生由宿主唯一分发，前端不再重复执行。面板事件只在浮岛有document焦点且可见时处理，浏览器预览允许聚焦面板验证；输入录制时临时暂停已注册全局快捷键需可靠恢复（如确有必要另记协议）。
