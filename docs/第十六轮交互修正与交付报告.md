# 第十六轮交互修正与交付报告

2026-09-22 · 版本 **0.3.6** · 交付源码 `6b7a41d0b09b46ffd8b64e0473f690e7ff920eb2`

## 用户反馈与处理

### 1. 布局改正（对第十五轮的纠正）

第十五轮误把"上移"实现成了"每列加标题行"。按用户标注改正为：**所有目录/组/最近项目列内不再有任何标题行**，当前目录名与返回按钮上移到面板顶栏（即用户红框标注的位置），各列网格由此天然横向对齐。

- `FolderBrowser.tsx`：列内标题行移除；`FolderHeaderControls` 增加 `name`，最深层列把当前目录名上报给顶栏；返回按钮在顶栏对所有有上级的深度可用。
- `RecentProjects.tsx`：列内"最近项目"标题行同样移除，改为经 `onHeaderChange` 把名称与刷新上报顶栏；顶栏刷新按钮在浏览目录和最近项目时都位于关闭按钮左侧（用户要求的"最右侧叉叉处刷新"原本即此布局，保持不变）。
- `GroupEntryMenu.tsx`：移除第十五轮的 withTitle 列标题。
- `Dock.tsx`：顶栏为 `[项目名 · N个入口 · 筛选框] … [←返回][当前目录名][↻刷新][✕关闭]`。
- `folder-browser.css`：清理已死的 `.folder-browser-path` 规则。

### 2. 一级菜单收藏星标缩小

- 主栏（dock-launchers）星标从 23×23px 缩到 17×17px（图标 10px），减少对小图标的点击遮挡；二级及以下菜单磁贴保持 23px 不变（用户确认那些没问题）。

### 3. 面板内搜索框（新功能）

- 顶栏左侧新增"筛选当前菜单"输入框：只对当前打开菜单（组列、所有已展开目录列、最近项目列）的**已加载内容**做客户端过滤，不产生磁盘 IO、不递归未展开目录。
- 模糊匹配（`src/core/searchMatch.ts` 新增 `fuzzyIncludes`）：子串包含 + fzf 式有序子序列 + 空格分词，中英文均可（如"文4"命中"文件4.txt"）。
- 输入框内 Escape 先清空筛选（不关闭面板），再按 Escape 才关闭；输入期间面板快捷键按既有规则暂停；切换项目/入口或关闭面板时自动清空。

### 4. 所有子菜单右键纵向拖动

- 新 `useMenuPan`（组合既有 `useBlankPan` + `useRightPan('y')`）：组列、目录列、最近项目列的滚动面统一支持**右键按住拖动纵向平移**（抓取方向：上拖=下滚）；左键空白抓手与主栏右键横拖保持不变。
- 取舍（用户委托决定）：不引入额外长按计时——**右键拖动超过 7px 即平移并抑制右键菜单；原地右击（未移动）照常打开菜单**。与主栏既有模式一致。拖动后 500ms 抑制窗会吞掉紧随的一次右击（既有主栏行为，测试已覆盖等待后的点击）。
- 两个断言旧行为（目录右键不拖动）的 e2e 同步反转：`eleventh-shortcuts.spec.ts:132`、`thirteenth-gestures.spec.ts:108`。

### 5. 搜索模糊化

- 全局搜索窗"已保存文件/目录轻度模糊匹配"从默认关改为**默认开**（软件别名原本默认开）。
- 驾驶舱"搜索全部"弹窗从纯子串改为 `fuzzyIncludes` 模糊匹配。
- 面板筛选框同上。原生 Windows 索引查询路径不变（协议未动）。
