# Luma Quick Launch 发布与打包

- 仓库：`sfex1320/luma-quick-launch`，初始为私有仓库。
- 产品名称保留 Luma；英文仓库名称为 Luma Quick Launch。
- 当前版本：`0.2.0`，目标平台 `win-x64`，便携 ZIP 与安装 EXE。
- 源码与构建脚本进 Git；运行包放在 GitHub Release，不将二进制依赖提交到 Git。

## 构建

安装 Node.js 22.12+、.NET SDK（版本见 `native/global.json`）、Microsoft Edge 与 WebView2 Runtime，执行：

```powershell
npm ci
powershell -ExecutionPolicy Bypass -File scripts/package-release.ps1
```

脚本在 `releases` 下建立全新暂存目录，执行前端测试、生产构建与内核测试，收集第三方许可，生成 ZIP 和 SHA256，再解压校验每个文件。最后对**解压后的程序**执行真实 WebView2 / Windows Shell 集成测试，成功才报告可发布。集成测试当前需要双屏 Windows 桌面；不以浏览器模拟替代。

产物：`releases/luma-quick-launch-0.2.0-win-x64.zip` 及同名 `.sha256`。同版本文件已存在时脚本停止，避免覆盖已发布包。每次打包日志在对应 `releases/build-*` 下保留，不进入 Git 或 ZIP。除标准 18 项原生检查外，验证解压 exe 的真实桌面/开机启动操作与独立启动/退出生命周期，备份并恢复用户系统入口。

便携包通过后，以日志中的解压目录作为 `-SourceDirectory` 执行 `scripts/build-installer.ps1`，生成 `luma-quick-launch-0.2.0-setup-x64.exe` 与 SHA256。安装器详细行为、固定编译器校验与真实安装测试见 [安装版构建说明](installer-readme.md)。两种分发使用同一套已验证 exe/前端资源。

若原工作区 `APP/native/Luma/Luma.exe` 正在运行，集成验证期间暂时退出该实例，测试结束后重新启动；配置文件不会替换。其他目录中的实例不会主动停止。

## 发布

确保测试通过、源码已提交且工作区干净。GitHub Release 使用与源码版本一致的 `v0.2.0` 标签，附便携 ZIP、安装 EXE、各自 SHA256 和简明说明。

## 内容边界

发布前回归补充：原生窗口改变命中区域后，WebView 可能在鼠标未移动时再次发送 pointer-enter。原生浮岛只由宿主的物理移出再进入规则触发悬停展开，避免前端 180ms 定时器绕过该规则。浏览器预览仍保留悬停展开；手动展开、拖入与原有 650/600ms 动效不变。回归用例额外模拟命中区域变化后的 enter，修改前稳定失败。

- 不收集 `%LOCALAPPDATA%/Luma` 配置、浏览记录或用户图标缓存。
- `.gitignore` 排除依赖、编译输出、凭据、运行日志与本机测试原始证据。
- 修复报告保留在 Git 中；其中本机证据路径不代表可在其他机器直接访问。
- 不额外授予项目开源许可；第三方组件遵循随包提供的许可。
- 运行包依赖 WebView2 Runtime；安装版为当前用户安装，不提升权限，不修改系统索引范围。
