# 第十三轮：抓手滚动与快捷键

## 实现

- 主工具条保留右键水平拖动；目录、集合、最近文件子菜单改为左键空白抓手，7px 后开始滚动，按钮长按与引用拖拽不受空白抓手接管。
- 多入口软件组只显示全宽“进入”；单软件保留“打开软件 / 最近”。取消图标角落的展开箭头，长按、悬停进入和右键入口保留。
- 设置与备份新增快捷键卡片，可录制 Ctrl / Shift / Alt 任意组合和单键，绑定主面板、搜索、设置、整理、项目或成员。当前目录的打开、新建、复制、运行项目使用已有目录令牌操作。
- 用户已确认单键仅面板有焦点时生效；组合键可全局。输入框、录制、IME 和对话框不触发面板快捷键。全局注册冲突显示实际状态，录制期间暂时释放，结束/失焦/退出恢复或清理。
- 原生按配置 ID 执行，配置删除、改绑、排队或窗口查找期间失效时停止；重复按键不重复启动，沿用窗口复用服务。项目展开等动作等待真实浮岛恢复、布局确认后发送。
