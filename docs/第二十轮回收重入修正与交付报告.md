# 第二十轮回收重入修正与交付报告

2026-09-23 · **0.4.2** · 交付源码 `c7b392396ff3d8f3bd4638171016f28bcddba16d`

## 核查与根因

仓库 `sfex1320/luma-quick-launch` 已公开，简介和话题完整；开始工作时实际运行的是 `APP/Luma/Luma.exe` 0.4.1。本轮重新打包并直接替换为 0.4.2，不能仅凭版本号推断功能正确。

第十九轮的回收重入结论不充分：子菜单同时受到父容器位移和自身 CSS 位移影响，window.sync 只扣除了父位移。子菜单动画结束引发同步时，命中矩形会向上缩，鼠标回到二级菜单原位置无法取消回收；主栏的区域仍在，所以主栏能重入。新增回归在旧实现上明确失败。

旧子菜单延迟仅为自身时长的25%，并不满足“一级先完成、二级随后”。本轮将主栏与子菜单拆为同级独立动画，以一级下边界裁剪子菜单。三个速度档主栏推出/收回仍为650/600、520/450、380/320ms，子菜单随后以200/160/120ms滑动，全程不淡出。反转从当前帧开始，二级保持当前帧直至一级重新到位；两层结束后才提交 collapsed。

命中区域扣除各自独立位移，保留静止区域与扫过区域到当前回收完成，没有逐帧同步，也没有增加隐藏状态的唤醒窗。拆分时同步迁移 `.dock-stage .stack-panel` 的宽度、flex 和滚动约束，避免短视口底部按钮溢出；裁剪层不再制造页面滚动条。

## 收藏、材质与文档

- 主栏、组列、目录列、最近项目列的收藏按钮仍统一只在整理模式出现，相关回归通过。
