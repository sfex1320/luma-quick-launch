# Luma 图形标志

三层悬浮玻璃叠片表示文件夹组合与向下展开的面板；仅图形，无文字、字母或数字。

- 主图：`luma-source.png`，通过内置 image_gen 工具生成，再按用户要求统一为鼠尾草绿、苔绿和深森林绿，保留透明背景。
- 最终提示：保留三层圆角玻璃叠片的形状、光照、透明度与构图；将蓝/青/钴蓝全部替换为 pale sage #d9efc5、moss #8aaa70、forest #31594a；无文字、字母、新符号。
- `scripts/make-icon.ps1` 仅进行尺寸转换，输出原生与网页共用的 16/20/24/32/40/48/64/128/256 像素 ICO 及 256 像素 PNG。小尺寸和主图使用同一标志。
- EXE、托盘、原生标题栏、安装器、网页 favicon、设置页品牌与加载页均使用本标志。应用名称可在标志旁正常显示，不进入 Logo 图像。
